# 画板交互与响应式说明

路由细节以 [`docs/interaction-flow-v2.md`](../interaction-flow-v2.md) 为准。这里列出与已导出画板对应的主要动作；Figma 画板用于视觉参考，未标注的交互不应推断为已经做成可点击原型。

| 入口 | 目标 / 行为 | 画板 |
| --- | --- | --- |
| 首页“开始提问” | 进入 `/chat/new` 并聚焦输入框；不自动发送，也不提前创建空会话 | `10:94` |
| 首页常办事项卡及加号 | 进入 `/services?category=<对应分类>`；卡片和加号使用同一目标 | `10:94`、`22:131` |
| 对话来源入口 | 桌面打开右侧来源栏；手机打开来源抽屉，归属当前选中的回答 | `10:95`、`10:96` |
| 来源标题 / 原文 | 新标签打开已有来源 URL；缺失或失效时保留信息并显示状态，不构造链接 | `10:95`、`22:70` |
| 历史会话项 | 打开 `/chat/:conversationId` 并恢复该会话；空列表使用“暂无历史对话” | `10:94`、`22:70` |
| 登录 / 注册 | 登录成功后回到触发登录的操作；关闭面板保留当前页面与输入内容 | `22:35` |
| 办事指南列表项 | 打开 `/services/:serviceId`；返回保留分类和搜索状态 | `22:131`、`22:176` |

现有设计只提供 `1440` 桌面画板和 `390 × 844` 手机问答画板。`1024` 与 `768` 的断点布局、手机来源抽屉展开、焦点与禁用控件状态都没有定稿稿件；请按 `docs/interaction-flow-v2.md` 实现后，通过浏览器回归记录推断与差异。
