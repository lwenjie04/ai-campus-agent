# 画板交互与响应式说明

路由细节以 [`docs/interaction-flow-v2.md`](../interaction-flow-v2.md) 为准。Figma 画板用于视觉与断点参考，未标注的交互不应推断为已经做成可点击原型。

| 入口 | 目标 / 行为 | 画板 |
| --- | --- | --- |
| 首页“开始提问” | 进入 `/chat/new` 并聚焦输入框；不自动发送，也不提前创建空会话 | `10:94` |
| 首页常办事项卡及加号 | 进入 `/services?category=<对应分类>`；卡片和加号使用同一目标 | `10:94`、`22:131` |
| 对话来源入口 | 桌面打开右侧来源栏；手机打开来源抽屉，归属当前选中的回答 | `10:95`、`10:96` |
| 来源标题 / 原文 | 新标签打开已有来源 URL；缺失或失效时保留信息并显示状态，不构造链接 | `10:95`、`22:70` |
| 历史会话项 | 打开 `/chat/:conversationId` 并恢复该会话；空列表使用“暂无历史对话” | `10:94`、`22:70` |
| 登录 / 注册 | 登录成功后回到触发登录的操作；关闭面板保留当前页面与输入内容 | `22:35` |
| 办事指南列表项 | 打开 `/services/:serviceId`；返回保留分类和搜索状态 | `22:131`、`22:176` |
| 移动首页“最近对话” | 打开对应 `/chat/:conversationId` 并恢复会话 | `33:176` |
| 移动端来源入口 | 从屏幕底部打开来源抽屉；关闭后回到当前回答 | `33:300` |
| 平板端来源入口 | 打开右侧来源抽屉；关闭后保留当前问答位置 | `33:259` |
| 移动端登录 / 注册 | 登录或注册完成后返回触发登录的操作；错误信息显示在表单附近 | `33:332` |
| 移动端办事指南项 | 进入对应事项详情；列表搜索和分类以路由状态为准 | `33:355` |

## 响应式规则

| 宽度 | 布局规则 | 对应画板 |
| --- | --- | --- |
| 1440 | 首页使用居中内容列；问答保持阅读区与来源侧栏并排 | `10:94`、`10:95` |
| 1024 | 导航仍为横向；首页使用三列事项卡与右侧回答预览；问答保留右侧来源栏 | `33:92`、`33:212` |
| 768 | 首页保留横向导航并压缩卡片宽度；问答来源改由右侧抽屉覆盖 | `33:135`、`33:259` |
| 390 | 紧凑顶栏与单列内容；首页保留常用服务和最近对话；问答输入区固定底部；来源从底部抽屉展开 | `33:176`、`33:300`、`10:96` |

控件状态样例见 `35:134`：主按钮 default/hover/focus/disabled，次要按钮 default/focus/disabled，输入框 default/focus/error，来源卡片收起与展开。实际点击行为由前端实现，并按 [`docs/interaction-flow-v2.md`](../interaction-flow-v2.md) 与浏览器回归结果校验。
