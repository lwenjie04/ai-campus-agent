### 2.9 真实 Embedding 混合权重调优（隔离副本，未改生产）

为下一批发布准备「真实向量上线」参数，避免启用后出现低可信命中或答案质量回退。数据：660 切片 + Top20 金标 + 独立留出集 + 5.4 草稿集（50 正例 + 10 负例；草稿尚未人工签核，仅作稳健性参考）。

基线（关键词或 hash 向量，`minScore=3`）：Top20 **18/20（90%）**、留出 **8/10（80%）**、草稿 **47/50 + 负例 9/10**。

| 配置（真实 bge-m3 索引） | Top20 | 留出集 | 草稿 正例/负例 |
| --- | --- | --- | --- |
| `RAG_WEIGHT_VECTOR_SCORE=6`（默认） | 18/20 | 9/10 | 47/50 + 7/10 |
| `=14`，`minScore=3` | 19/20 | 9/10 | 48/50 + 4/10 |
| `=20`，`minScore=3` | 20/20 | 9/10 | 49/50 + **3/10** |
| `=20`，`minScore=15` | 19/20 | 9/10 | 48/50 + 9/10 |
| `=14`，`minScore=12` | 19/20 | 9/10 | 48/50 + 9/10 |
| 对照：关键词/hash + `minScore=12` | 18/20 | 9/10 | 47/50 + 9/10 |

关键发现：

1. **只提权重的副作用明确**：草稿集负例（无答案问题）从 9/10 降到 3/10——默认 `minScore=3` 下弱语义命中 `cosine × weight` 仍可过门槛，会破坏「无法确认」的保守行为。
2. **余弦分布可分离**：匹配正例 top-1 余弦最低 **0.638**（中位 0.731）；负例最高 0.713（中位 0.532，仅 2 例超过 0.6）。
3. **复核对照**：在隔离副本给 `rag.mjs` 加 `RAG_VECTOR_MIN_COSINE=0.60` 门槛后，0/68 匹配正例被误滤、负例放行 10→2；`w14 + cos0.60 + minScore12` 为 Top20 19/20、留出 9/10、草稿 48/50 + 负例 9/10，**全面不劣于基线且正例 +1/+0/+1**；`w20 + cos0.60 + minScore6` 为 20/20、9/10、49/50 + 负例 8/10。

**建议（下一批发布）**：同时引入 `RAG_VECTOR_MIN_COSINE`（默认 0.60）并把 `RAG_WEIGHT_VECTOR_SCORE` 设为 14、`RAG_ANSWER_MIN_SCORE` 设为 9–12；上线后观察未命中与「无法确认」比例，保留 hash 索引与旧权重回滚。该实验只改 `/tmp` 隔离副本的 `rag.mjs`，**生产代码与配置未改**。
