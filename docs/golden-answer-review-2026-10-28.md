## 1. scholarship-national-award-amounts（scholarship）

**问题：** 2024-2025学年国家奖学金和国家励志奖学金的奖励标准分别是多少？

**模型回答：**

结论：2024-2025学年，国家奖学金为每生每年10000元，国家励志奖学金为每生每年6000元。该标准自2024年起执行。

关键信息：
1. 依据财政部、教育部等2024年调整国家奖助学金政策的通知，以及学校2024-2025学年评审工作通知。
2. 学校学生手册中的旧标准（国家奖学金8000元、国家励志奖学金5000元）已不适用，仅作历史参考。
3. 同一学年内不能同时获得国家奖学金和国家励志奖学金，但可同时申请国家助学金。
4. 国家奖学金和国家励志奖学金一般于每年12月31日前一次性发放。

提醒：具体评审安排和名额以学校当年官方通知为准。

## 2. teaching-semester-registration（teaching）

**问题：** 每学期开学学生没能按时注册，要办理什么手续？

**模型回答：**

结论：不能按期注册的，须办理暂缓注册手续；未缴学费或不符合注册条件的，不予注册。

办理步骤/关键信息：
1. 在开学前或注册期间，向所在院（系）说明不能如期注册的原因，履行暂缓注册手续。
2. 院（系）会按病假、事假、旷课或其他原因如实记载未按时注册情况。

## 3. teaching-transfer-conditions-handbook（teaching）

**问题：** 普通本科生申请转专业要符合什么基本条件？

**模型回答：**

结论：普通本科生申请转专业，需确有专长、兴趣和意愿，对所申请转入专业具有较好的学习能力，且学籍状况正常、不属于禁止转专业的情形。

办理步骤/关键信息：
1. 基本条件：入学后一般应在被录取专业完成学业，确有专长、兴趣和意愿，转专业更能发挥专长、利于发展，可申请转专业；不限年级、不限次数，每人每次只能申请一个专业。
2. 禁止情形：招生时明确规定不能转专业者（如定向生、国防生等）；特殊录取类型申请转入统招专业者（如免试生、专插本、三二分段、五年一贯制、第二学士学位等）；休学、保留学籍等学籍状况不正常者；其他规定不能转专业的情形。
3. 特殊情形：因休学创业、退役后复学，或身体原因不能完成现专业但能完成其他专业学业，或特长特殊、确有特殊困难不转专业无法继续学习的，可不受时间限制提出申请，经学校审核后报分管校领导批准。
4. 申请时间与流程：学校每学年第一学期第14至20周统一受理；第15周填写转专业申请表提交所在二级院系，之后经资格审核、公示、综合考核、学校教学指导委员会审核、公示等环节确定名单。

提醒：以上依据学校普通本科生转专业管理规定（2018年修订），具体接收专业、人数、申请条件和考核方式以当年各二级院系公布方案及教务处最新通知为准。

## 4. teaching-grade-point-average（teaching）

**问题：** 平均学分绩点按什么公式计算？

**模型回答：**

结论：平均学分绩点按“∑（课程绩点×课程学分）÷∑课程学分”计算，结果保留小数点后两位。

关键信息：
1. 课程绩点＝（课程考核成绩－50）÷10；考核成绩在60分以下的课程，绩点记为零。
2. 课程学分绩点＝该课程绩点×该课程学分数。
3. 学期平均绩点＝该学期取得的学分绩点总和÷该学期所修课程的总学分。
4. 在学期间的平均绩点＝在学期间取得的学分绩点总和÷在学期间所修课程的总学分。
5. 经补考及格的课程，按实得成绩记分并给予学分，但绩点记为1；经重修、缓考及格的课程，按实得成绩记分和登记绩点。

提醒：以上依据学校成绩管理办法，具体以教务处最新规定和教务管理系统计算结果为准。

## 11. exam-violation-types（exam）

**问题：** 学校规定的考试违纪和考试作弊包括哪些情况？

**模型回答：**

结论：按《广东第二师范学院学生考试违规处分规定（修订）》，考试违规分为考试违纪和考试作弊两类，分别对应第四条和第五、六条列举的情形。

关键信息：
1. 考试违纪（第四条）主要包括：未在规定位置签名；携带规定以外电子设备或物品进入考场或未放指定位置；未经同意擅自借用文具；旁窥、交头接耳、互打暗号或手势；开考前答题或结束后继续答题；未经同意擅自离开考场；将试卷、答卷、草稿纸带出考场；在考场或禁止范围喧哗、吸烟等影响秩序；不服从监考管理、妨碍监考履职；无故旷考；未在规定座位考试；用规定以外笔纸答题或在答卷规定外位置写姓名、考号、标记信息；其他违反考场规则但尚未构成作弊的行为。
2. 考试作弊（第五条）主要包括：替考或让他人替考；使用与考试内容相关的通讯设备或器材；填写与本人身份不符的姓名、考号；抄袭或协助他人抄袭试题答案及相关资料；将考试内容抄在桌面、身体上或藏于试卷、课桌、衣物、文具内；交换试卷、答卷、草稿纸；抢夺、窃取他人试卷或胁迫他人为自己抄袭提供方便；以不正当手段获得或试图获得试题答案、成绩；故意销毁试卷等考试材料；携带发送或接收信息功能的设备，或携带与考试内容相关的材料、存储相关资料的电子设备参加考试；其他被认定为作弊的行为。
3. 其他认定为作弊的情形（第六条）：同一科目同一考场两份以上答卷作答雷同；伪造证件、证明、档案等获得或试图获得考试资格；出具、使用伪造的课程成绩和技能等级考试成绩证明；考试结束后用不正当手段更改答卷内容或成绩；组织考试作弊；向他人出售试题或答案牟利；其他扰乱考试秩序行为。
4. 处理后果：有上述行为之一的，取消相应课程考试成绩；其中替考、使用通讯设备作弊、组织作弊、出售试题答案等可给予开除学籍处分，具体处分等级按第七条至第十一条执行。

提醒：该规定自2020年4月21日起实施，由教务处负责解释；如学校后续发布新修订版本，请以最新官方通知为准。

## 14. scholarship-hardship-recognition-process（scholarship）

**问题：** 家庭经济困难学生认定要经过哪些评议和审核环节？

办理步骤/关键信息：

2. 班级民主评议：班级民主评议小组（班主任任组长）审核评定参评学生的家庭经济状况和在校生活表现，组织班级投票认定，并将结果报送院（系）。
3. 院（系）评定：院（系）学生资助工作组（党总支（副）书记任组长，辅导员、班主任为成员）评议每位参评者的经济困难状况并评定分值，测评结果在二级学院内公示三天。
4. 学校审核：校级学生资助工作组（学生工作处牵头）负责管理、协调和监督，学生资助管理科对院（系）报送结果进行审核。
5. 省级确认：最终由省学生助学中心确认认定结果。

关键信息：

## 17. life-dorm-residency-eligibility（life）

**问题：** 哪些学生可以在学校学生宿舍住宿？

**模型回答：**

结论：在学校正式注册接受学历教育、在规定学制年限内的学生，可以在学生宿舍住宿；未能在规定学制年限内毕业的，办理延期手续后，在最长学制年限内可由学校另行安排住宿。

办理步骤/关键信息：

2. 入住须按指定宿舍、床位入住，未经批准不得擅自变更、出让、出租或占用床位。
