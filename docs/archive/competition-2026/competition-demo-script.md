# 比赛主演示脚本（7 分钟）

> 历史归档：来自 `feat/backend-rag` 分支，保存点为 `9da3af7`。仅用于复现 2026 年比赛演示流程。

**版本日期**：2026-08-09
**核心主张**：数智校答不是通用聊天机器人，而是能给出可信来源、并由人工审核持续沉淀校园经验的数字人校园服务助手。

## 上场前 15 分钟

1. 在比赛电脑确认 `server/.env` 已配置模型、MySQL、管理员强密码、会话密钥和游客 Cookie 密钥；全程不要投屏展示该文件。
2. 如需重置演示数据，执行 `server/sql/community-demo-seed.sql`。该脚本只重置 `*_demo_*` 固定演示记录，可重复运行。
3. 运行 `npm run competition:check`，确认没有 `FAIL`；逐条阅读 `WARN`，不可只看最后一行。
4. 启动后端后运行 `npm run competition:smoke`，确认健康接口、匿名管理拦截和跨域预检全部通过；再启动 Web 和比赛需要的可选服务。
5. 开发机可先运行 `npm run competition:rehearse` 做 10 轮隔离自动彩排；它使用明确 Mock 且禁用外部 TTS，不能替代真实服务彩排。
6. 主演示首页使用新的无痕窗口，确保游客体验 Cookie 未被使用。管理员标签页提前登录，但不要在投屏中展示密码。
7. 关闭系统通知，接通电源，保留本地构建产物和关键词检索回退，不临场升级依赖。

## 稳定问题池

### 三个主问题

1. `普通本科生申请转专业需要什么条件？`
2. `2026年上半年英语四六级什么时候报名？`
3. `竞赛奖学金材料一般要提前准备哪些？`（用于社区知识闭环）

### 五个备用问题

1. `补考怎么报名？`
2. `收到学业预警后要怎么处理？`
3. `家庭经济困难学生认定怎么办理？`
4. `宿舍报修怎么申请？`
5. `第二学期两校区交通车怎么安排？`

除社区闭环问题外，主问题和备用问题都来自 `server/evals/competition-golden-questions.json`。不要用临场随机问题替代已验证问题来证明主链路。

## 现场异常恢复

| 异常 | 用户可见行为 | 30 秒内动作 | 可以说什么 |
|---|---|---|---|
| LightRAG 不可用 | 回答继续生成 | 不重启页面，使用自动本地检索回退 | “图谱检索不可用时会自动降级，正式来源仍可追溯。” |
| 模型网络失败/超时 | 明确提示“未生成答案”，保留已检索来源，本次游客额度不扣除 | 打开来源或改用备用问题重试一次 | “系统没有伪造答案，并保留了可以核验的正式资料。” |
| TTS 不可用 | 文本和来源正常，数字人停止播报后回到待机 | 静音继续讲解，不连续点击播放 | “语音是增强层，核心问答不依赖它。” |
| MySQL 不可用 | 若显式启用比赛内存回退，强管理员仍可登录并查看内存审核数据；注册关闭，实时知识入库不可证明 | 跳过闭环最后一步，展示已打开的审核界面 | “数据库当前离线，所以我们不声称这次审核已经进入真实检索。” |
| 页面或投屏异常 | 当前标签不可操作 | 切到预先打开的备用标签；必要时使用 `dist` 本地预览 | “我切换到同版本的本地构建继续演示。” |

## 不可跨越的演示红线

- 不展示密钥、密码、真实学生隐私或 `.env` 内容。
- 不把社区经验说成学校正式政策。
- 外部服务失败时不把 Mock 回复包装成真实模型答案。
- 现场发现来源不符时立即换备用问题，并在赛后记录，不强行解释为正确。
