## 4. 当前主要风险

### 4.1 Git 工作区未整理

当前状态：

- 本地 `master` 落后远端 1 个提交
- 存在已修改文件
- 存在已删除文件
- 存在大量未跟踪文件

风险：

- 后续提交时容易混入临时文件、数据文件或大文件
- 不利于交接和部署
- 不利于判断哪些改动属于正式功能

建议：

- 先区分“源码 / 文档 / 数据 / 临时文件 / 归档文件”
- 再决定哪些需要纳入 Git
- 临时文件、缓存、OCR 训练数据、大型中间产物建议加入 `.gitignore` 或转入归档目录

### 4.2 RAG 测试超时

现象：

- `npm run rag:test` 未能在 120 秒内完成

可能原因：

- embedding 服务网络访问慢
- 远端接口超时
- 测试脚本对每个问题实时请求 embedding
- 当前 `VECTOR_EMBEDDING_TIMEOUT_MS` 设置偏长或请求串行

建议：

- 先使用单问题测试定位卡住的查询
- 临时切换 hash provider 验证本地检索流程
- 再切回真实 embedding 服务做效果评估

### 4.3 真实环境联调仍需确认

需要确认的配置：

- DeepSeek / OpenAI compatible LLM API
- embedding API
- MySQL
- 邮箱 SMTP
- 腾讯云 TTS
- Nginx 反向代理

风险：

- 本地代码可构建，不代表服务器端依赖全部可用
- 社区 fallback mock 可能掩盖数据库连接问题

### 4.4 移动端尚未完成

当前移动端是独立骨架，尚未达到主项目同等完整度。

建议：

- 若近期目标是答辩演示，移动端可标为“后续拓展”
- 若目标包含小程序 / H5，则需要单独排期
