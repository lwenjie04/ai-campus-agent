# 办事指南事项清单（V2 草案）

**状态**：人工已确认，可用于办事指南列表；年度流程仍以最新学校通知为准。
**核对日期**：2026-10-26。
**结构化数据**：[`service-catalog-v2.json`](service-catalog-v2.json)。

## 范围

清单共 12 项，按现有前端分类 ID `teaching`、`exam`、`scholarship`、`life` 组织，每类 3 项。数据包括稳定 ID、标题、关键词、用途、提问模板、来源标题/定位和核对日期，满足 5.1 的字段要求。用户于 2026-10-26 确认：可以使用此事项范围，旧年度通知只作为来源参考。

来源定位优先采用《2025 年学生手册》的制度标题和条款，或仓库已导入的学校通知记录。DOCX 导入文本没有保留手册页码，因此手册来源使用制度章节/条款定位；无法定位到页面的已在条目中标出。

## 发布边界

- 所有条目的 `actionUrl` 暂为 `null`，前端不应显示“立即办理”或其他办理入口。
- 通知页链接只作为来源参考，不等于当前可办理入口；应按条目中的 `freshness` 更新本学年通知后再展示。
- 本地通知库目前收录到 2026 年上半年/2025–2026 学年。转专业、补考、四六级、奖助学金、宿舍调整等时限性内容只作为来源参考，不作为 2026–2027 学年的当前流程。
- 手册封面日期为 2025-08-28，但其中部分制度标注为 2016、2017、2021 年发布。已避免在清单中固化金额、名额、截止日期和未核实的操作步骤；当前有效性仍需人工确认。
- 本轮检查的是仓库中的手册与已导入通知数据。学校官网的实时页面未能通过本会话浏览工具打开，引用链接的当前可访问性也未确认。

## 交接

AI-1 可按 JSON 字段接入列表和详情，并对空 `actionUrl` 隐藏办理入口。年度规则、申请时间和流程应由提问模板引导查询最新学校通知；来源或流程无法确认时，不展示办理按钮或过期时限。
